# Котик — обновления

Здесь лежат готовые версии Котика (кот на экране) для телефона и для ПК.
Котик сам берёт отсюда обновления (раз в несколько часов или по кнопке «Проверить обновления»), сервер не нужен.

- `android.txt` + `Kotik-X.Y.apk` — телефон
- `pc.txt` + `Kotik-X.Y.exe` — ПК (обновление подписано, чужой файл Котик не поставит)
